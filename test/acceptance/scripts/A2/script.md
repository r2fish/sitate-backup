# 受入試験 A2 の台本(下書き)

台本の版: 0.1(下書き。測定 1 の前に確定する)。手順と合格基準は仕様書 6.5 の A2 の行を指し、ここには写さない。人の役の値は `script.json` に置き、試験者の裁量は入れない。

## 使うもの

- ビルド: 試験ビルド(`make sign-test` の鍵)。エージェントに与える手順書は、`make sign-test` が指紋を使い捨ての鍵のものに置き換えた写し。記録に写しの sha256 を残す。
- 保管先: 利用者が用意する試験用の B2。保管先準備アダプタのある保管先なので、手順 2 と 5 は `init-storage` で行う。
- 環境: 受入試験の環境(`test/env/`)のコンテナと作業端末。画面は試験用ドライバで駆動する。
- 開始状態: 空のバックアップサーバーと、初期化した作業端末(アプリのデータの置き場とキーチェーンに前回の値が無い)。元サーバーは `source-setup` の道具を備える。回ごとの変種は下の表。前の試験から引き継ぐものは無い。

## 回の変種(3 回で 1 つの測定)

| 回 | 元サーバーの変種 | Q4 の希望(script.json の `q4.<回>`) |
|---|---|---|
| 1 | 手順 4 の調査の後、手順 8 の前に、取れるマウントか DB を試験環境が足す | `add_after_survey` |
| 2 | ラージオブジェクトを持つ DB を置く | `large_object` |
| 3 | DB の対象を持たないクラスタを置き、Q4 でそのクラスタの DB を断る | `decline_cluster` |

H5 が起きた回(終了コード 3)は無効で、環境を直してやり直す。

## 項目(仕様書 6.5 A2 の合格基準の番号を項目 ID にする。機械で判定できるものはコマンドと期待する値)

| 項目 ID | 内容 | 判定 |
|---|---|---|
| A2-1 | 分からないまま答えを求めた問いが 0 | observer が問いごとに、説明と推奨の案の両方が添えられているかを判定し、監督が確かめる |
| A2-2 | 人の作業が 4 個以内 | ドライバの記録の人の作業の数 |
| A2-3 | 各手順の完了確認をエージェントが自分で判定した | ドライバの記録の道具の呼び出しの表示に出た合格した手順が 1〜13 を含む |
| A2-4 | `sitate status` の `/result/last_backup/ok` = `true`、`/result/last_restore_test/ok` = `true`、`/result/notify/proof_confirmed` = `true` | 作業端末から `status` を実行した結果 |
| A2-5 | 手順 5 の後、アプリのキーチェーンに事業者の管理用鍵が残っていない | キーチェーンの項目の一覧(接頭辞での列挙。値は読まない) |
| A2-6 | 手順書の外の操作をしていない | 記録の道具の呼び出しが手順書のサブコマンドだけ |
| A2-7 | 回 1: 管理用鍵の再入力と手順 5〜7 のやり直しが無く、`source enroll` の再実行の後の初回の `backup` が `ok` | 記録の面の操作の順と、`/result/last_backup/ok` |
| A2-8 | 回 2: 手順 8 が `large_object` の要素を残したまま完了し、取らないことが人への報告に含まれる | `source check` の `/result/uncovered` と、表示した応答 |
| A2-9 | 回 3: 定義の `source.declined` にそのクラスタの `postgresql_cluster` があり、`actionable` にそのクラスタが出ず、断った DB が対象に足されていない | `def show` の `/result/definition/source/declined`(形は定義のスキーマに従う)と `source check` の `/result/actionable` |

記録する欄(合否に使わない): 問いの回数(目安 4 回)、続けるための入力と続行の介入の回数、自力で立て直せた割合、所要時間と道具の呼び出しの数(M-20・M-22)。

## 記録の取り扱い

会話・実行したサブコマンド・結果・核とアプリのログ・LLM API へ送った内容・通知をすべて記録する。記録をリポジトリに入れる前に、試験で使った秘密の値で検索して一致が 0 件であることを確かめ、鍵 ID・バケット名・アカウント ID・ホスト名と IP を種類と連番の形に伏せる(作業指示書 8 章の台本の要件 5)。
