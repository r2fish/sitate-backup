# 元サーバーの /home・/srv を名前つきの volume に置く(D-0185)

2026-11-04。作業指示書 5.1b の追加の完了条件(D-0185)。環境名 r2vol(終了後に down 済み)。

## 変更

- `test/env/accept/compose.yaml`: source に名前つきの volume を 2 つ(`sitate-acc-<名前>-source-home` を `/home` へ、`sitate-acc-<名前>-source-srv` を `/srv` へ)。合成データ(`gen-source-data`)・所有者・権限・ACL の付け方は変えない(生成は volume の上へ書くだけ)。
- `test/env/bin/accept-env.sh`: `down` が `dc down -v` に加えて 2 つの volume を名指しで消す。`check` に「`/home`・`/srv` がマウント点で `stat -f -c %T` が candidate の種類(ext2/3・ext4・xfs・btrfs)」の検査を足した。
- `test/mainpath/stage3_survey_test.go`: `checkSurveyDirsSupported`。`source survey` の `dirs[]` のうち label が `home`・`srv` のものがすべて `supported: true` かつ `fs_type` が candidate であることを第 3 段で確かめる。
- `test/mainpath/stage2_test.go`・`stage3_rootchange_test.go`・`stage3_kinds_test.go`: 定義の `source.declined` に `{"id":"d2","mount":"/home"}` を足した(下の「/home のマウント」)。

## 試験

- 先に赤を確かめた: `test/env` の変更を退避して(= 今の main の環境)`make test-mainpath STAGE=3 NAME=r2vol` を流すと、新しい検査で `dirs[] の home の下が supported: true の candidate の種類でない: fs_type="overlay" supported=false` が home 3 件・srv 2 件で出て `--- FAIL: TestStage3MainPath`。
- 変更後: `make test-mainpath STAGE=3 NAME=r2vol` は `--- PASS: TestStage3MainPath (473.67s)`、`/home・/srv の下 5 件のうち supported: true でないもの 0 件`。
- `make test-mainpath STAGE=DB NAME=r2vol`(第 3 段の後の同じ環境では失敗する。別に作った環境で流す前提)は新しい環境で `--- PASS: TestStageDB (25.20s)`。
- `make test` は失敗なし(`ok` 73 行)。
- `accept-env.sh check r2vol --fast`: `集計: ok=50 FAIL=1`。唯一の FAIL は「リポジトリの追跡ファイルに生成した鍵・ユーザー名・証明書が無い」で、検査の文字列(`BEGIN OPENSSH PRIVATE KEY` など)が `accept-env.sh` 自身に当たる既存の自己一致。今回の変更とは無関係(新しい検査 1 件は ok)。

## /home のマウント(設計に係る事実)

`/home` が別のマウントになると、spec 3.3 の判定で `parent` になり、その下にファイルの対象の根が無ければ `source check` が `mount_parent`(足せる候補)を返し、手順 8 の `actionable = []` を満たさない。主経路の試験(Go)は定義に `declined` の `mount: /home` を足して通した。偽の LLM の通し(`test-app-e2e`)は `app/test/e2e/fake-definition.ts` が `mount`・`db` の候補だけを足し `mount_parent` を扱わないため、手順 8 で止まる(3 変種とも `台本に無い人の作業で止まった`、`steps_passed` に 8 が無い)。実際の LLM でも、この環境では手順 8 で `mount_parent` が出る(エージェントは直下の候補を Q4 の続きとして示して足すか、人が断って `source.declined` に書く。spec 6.2.2 手順 8)。
