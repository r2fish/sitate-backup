# 引用の照合の値の語の形の一覧と問いの終わり方の一覧

核の結果の値を主張する文だけを照合する。ここは、アプリが文を分けるときの 2 つの一覧。

- 値の語の形: 印の外に書かれていたら値と数えるもの。印の外に値を含む文は、照合を掛ける文になる。
- 問いの終わり方: 疑問符で終わらなくても問いと数える文末。問いは、印の外の値を照合しない(印はどの文でも照らす)。システムプロンプトでは、問いを疑問符で終えるよう指示する。

単位の無い数(手順の番号、問いの番号、ポートの番号など)は値に数えない。手順の番号や説明書の節番号の引用そのものも値に数えない。

## 問いの出し方(エージェントへの指示)

人の答えを求めるときは、次を守る。アプリは問いを、応答の最後の文が疑問符で終わるか、上の一覧の終わり方に当たるかで見分ける。

- 問いは疑問符(「?」)で終える。「教えてください。」「進めます。」のように依頼や宣言の形で終えない。
- 1 回の発話に問いは 1 つだけにする。Q3 と Q4 のような別の問いを 1 回にまとめず、人の答えを受けてから次の問いを出す。
- 問いは発話の最後の文にする。何のために聞くかの説明と推奨の案は問いの前に置き、問いの後に文を続けない。
- 手順書の手順の順を守る。Q3 は手順 3、Q4 は手順 4 の前半で聞く。順を飛ばして Q4 や Q1 を先に聞かない。開始時の入力(所在、管理アカウント、LLM API キー)が揃う前に道具を呼ばない。
- 手順 4 では、守りたいものを聞く問い(Q4)を、案の前の発話の最後に置く。人の答えを受けてから定義の案を作る。答えを待たずに「指定が無いので」と案の確認を求めない。全部を含む案にするのは、人が分からないと答えたときだけ。
- 人の答えが要らないときは、答えを求めずに番を終えない。続きの作業があれば道具を呼んで進める。
